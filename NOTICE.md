## Description of derivative modifications

The NyxLink development line contains substantial modifications, including:

- Multi-backend Lavalink v4 and NodeLink compatibility, capability detection
  and typed extension contracts.
- Playback intent management, failover, migration, queue and recovery
  improvements with regression and integration tests.
- Optional Redis persistence, distributed guild ownership, voice IPC fencing,
  and private metrics.
- Updated examples, TypeScript declarations, diagnostic redaction and
  automated release and backend compatibility tests.
